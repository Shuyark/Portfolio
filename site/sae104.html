Semestre 1 HTML / CSS Web design Cyberpunk
01Description / Objectif

Ce projet consistait à réaliser un site Web multipages en HTML et CSS sur un thème libre. Le cahier des charges demandait au minimum trois pages : une page d'accueil visuelle, une page riche en contenu sur le sujet choisi et une page à propos présentant l'auteur. Le site devait aussi respecter une charte graphique cohérente, être responsive, utiliser Flexbox ou CSS Grid, intégrer au moins une animation CSS, être publié sur GitHub Pages et disposer d'un README détaillé.

J'ai choisi le thème Cyberpunk, car c'est un univers qui me passionne, autant à travers le jeu vidéo que l'anime. J'aime son ambiance futuriste, ses villes lumineuses, ses contrastes entre technologie et société, ainsi que son esthétique très marquée. Ce thème me permettait donc de créer un site visuel, personnel et cohérent avec mes goûts.

Avant de commencer le développement, j'ai d'abord réfléchi au sujet, aux pages nécessaires et à l'organisation du travail. J'ai aussi utilisé Trello et réalisé un tableau de Gantt afin de planifier les étapes du projet et de respecter les délais : recherche du thème, création de la page d'accueil, ajout du contenu, mise en forme CSS, responsive design, validation et mise en ligne.

Mon rôle personnel : ce projet était individuel. J'ai donc assuré l'ensemble du projet : choix du thème, rédaction du contenu, création des pages HTML, mise en forme CSS, organisation du planning, tests responsive et mise en ligne.

02Vocabulaire
  • HTML5 : langage de balisage utilisé pour structurer le contenu d'une page web.
  • CSS3 : langage utilisé pour mettre en forme une page web : couleurs, tailles, placement, animations et responsive design.
  • Responsive design : adaptation d'un site aux différentes tailles d'écran, comme ordinateur, tablette ou téléphone.
  • Flexbox : outil CSS permettant d'aligner et de répartir des éléments facilement dans une interface.
  • Grid : système CSS permettant de créer des mises en page en lignes et colonnes.
  • DevTools : outils intégrés au navigateur pour inspecter, tester et corriger une page web.
  • Glitch : effet visuel inspiré d'un bug numérique, utilisé ici pour renforcer l'ambiance Cyberpunk.
  • GitHub Pages : service permettant d'héberger gratuitement un site statique à partir d'un dépôt GitHub.
  • W3C : organisme définissant les standards du Web, utilisé ici pour vérifier la validité du code HTML/CSS.
  • WCAG : règles d'accessibilité permettant de rendre un site plus utilisable pour tous les visiteurs.
  • Trello : outil d'organisation visuelle utilisé pour suivre les tâches à faire, en cours et terminées.
  • Gantt : tableau d'organisation permettant de planifier les tâches du projet dans le temps.
03Apprentissages critiques (AC)
  • AC13.01 – Utiliser un système informatique et ses outils – Utilisation d'un éditeur de code, du navigateur, des DevTools, de GitHub et de GitHub Pages pour produire, tester, corriger, versionner et publier le site Cyberpunk.
  • AC13.04 – Connaître l'architecture et les technologies d'un site Web – Création d'un site multipages avec des balises sémantiques HTML5 (header, nav, main, section, footer), une charte graphique cohérente, des animations CSS, Flexbox/Grid et une adaptation responsive.
  • AC13.06 – S'intégrer dans un environnement propice au développement – Organisation du projet avec un planning de type Gantt, plusieurs commits GitHub au nom explicite et un README présentant le projet, les technologies utilisées et le lien vers l'hébergement.

06Problèmes rencontrés / points complexes

Le premier problème a été de transformer un thème très visuel, le Cyberpunk, en un site lisible et structuré. Il fallait garder une ambiance forte avec des couleurs, des images et des effets, sans rendre la navigation confuse ou fatigante pour le lecteur.

Le responsive design a aussi été une partie complexe. Une mise en page qui fonctionne sur ordinateur peut devenir trop large, trop serrée ou mal alignée sur téléphone. J'ai donc dû ajuster les tailles, les espacements et l'organisation des blocs pour que le site reste utilisable sur plusieurs formats d'écran.

L'organisation du projet a demandé de la méthode. Entre les pages HTML, la feuille CSS, les images, le README, les commits GitHub et la mise en ligne, il fallait éviter de se disperser. Trello et le diagramme de Gantt m'ont aidé à découper le travail en étapes et à vérifier que le projet avançait dans le bon ordre.

07Autoévaluation

Apprentissages : Ce projet m'a appris à construire un vrai site multipages, à organiser mon travail avec un planning, à utiliser GitHub pour versionner le projet et à publier un site avec GitHub Pages. Il m'a aussi montré l'importance de penser au contenu, à l'accessibilité et à la validation du code, pas seulement à l'apparence visuelle.

Positionnement : Je me positionne en bonne maîtrise sur les bases HTML/CSS. Je suis à l'aise pour créer une structure de site, appliquer une charte graphique et rendre une page responsive. Je souhaite maintenant progresser en JavaScript pour rendre mes futurs sites plus interactifs.

Amélioration possible : je pourrais aller plus loin sur l'accessibilité, notamment en vérifiant systématiquement les contrastes, les textes alternatifs et la navigation au clavier. Ce serait important pour produire un site plus professionnel et utilisable par davantage de personnes.

08Preuves

Preuves : Ces éléments montrent à la fois le résultat final et la manière dont j'ai organisé mon travail. Le site en ligne prouve la production réalisée, tandis que Trello et le diagramme de Gantt prouvent la planification et le suivi du projet.

  • Site en ligne : cette preuve est la plus importante car elle montre le livrable final consultable par un utilisateur. Elle permet de vérifier la structure multipages, la navigation, le thème Cyberpunk, la cohérence graphique, les animations et l'adaptation du site à différents écrans.
  • Tableau Trello : cette preuve montre comment j'ai suivi l'avancement du projet. Elle permet de voir les tâches découpées, leur état d'avancement et l'organisation utilisée pour ne pas oublier les étapes importantes comme le contenu, le CSS, le responsive ou la publication.
  • Diagramme de Gantt : cette preuve montre la planification dans le temps. Elle sert à expliquer comment j'ai réparti les étapes du projet pour respecter les délais, depuis la recherche du thème jusqu'à la mise en ligne sur GitHub Pages.
