Traitement de données géographiques via API

Semestre 1 Python API REST OpenStreetMap Data Markdown
01Description / Objectif

Cette SAE avait pour objectif de créer un programme Python capable de récupérer des données géographiques depuis OpenStreetMap, de les traiter, puis de produire un résultat lisible sous forme de fichier Markdown ou HTML. Le projet ne consistait donc pas seulement à écrire du code : il fallait d'abord trouver un sujet exploitable, formuler une requête correcte, récupérer des données réelles et les transformer en statistiques compréhensibles.

Après une phase de recherche, j'ai choisi de travailler sur les supermarchés en Normandie. Ce sujet permettait d'utiliser des données OpenStreetMap concrètes avec le tag shop=supermarket, puis de comparer la présence de plusieurs enseignes comme Carrefour, Leclerc, Intermarché, Lidl et Auchan.

Mon rôle personnel : cette SAE était centrée sur mon propre programme. J'ai choisi le sujet, écrit la requête Overpass, adapté les scripts Python, corrigé les erreurs rencontrées et produit les fichiers de sortie Markdown puis HTML.

Le projet s'organisait autour de plusieurs étapes :

  • Définir un sujet assez précis pour obtenir des données exploitables dans OpenStreetMap
  • Écrire une requête Overpass pour récupérer les supermarchés situés en Normandie
  • Utiliser Python et la bibliothèque requests pour interroger l'API
  • Parcourir les réponses JSON afin d'extraire les noms et les informations utiles
  • Calculer des statistiques sur les enseignes les plus représentées
  • Générer automatiquement un fichier Markdown, puis le convertir en HTML
02Vocabulaire
  • API : interface qui permet à un programme de demander des informations à un service en ligne.
  • OpenStreetMap : base de données cartographique collaborative utilisée pour récupérer des informations géographiques réelles.
  • Overpass API : service permettant de faire des recherches précises dans les données OpenStreetMap.
  • Overpass QL : langage de requête utilisé pour demander à OpenStreetMap des objets précis, par exemple les supermarchés d'une région.
  • JSON : format de données renvoyé par l'API, organisé avec des listes, des dictionnaires et des paires clé/valeur.
  • Markdown : format simple permettant de produire un document lisible avec des titres et des listes.
  • HTML : langage utilisé pour afficher le résultat final dans une page web.
03Programmes Python réalisés

Plusieurs scripts Python ont été utilisés pour construire progressivement le projet :

  • sae15.py : script principal du projet. Il contient la requête Overpass sur les supermarchés en Normandie, la récupération des données, le calcul des statistiques et la génération du résultat.
  • fiche_osm.py : script permettant de récupérer les attributs d'un noeud OpenStreetMap précis à partir de son identifiant, puis de générer une fiche descriptive.
  • md_to_html.py : script plus court servant à convertir un fichier Markdown en fichier HTML grâce à la bibliothèque markdown.

Dans le script principal, la fonction de récupération interroge l'API Overpass, puis les données sont parcourues élément par élément. Le programme vérifie si chaque objet possède des tags et un nom, puis il compte les enseignes reconnues. À la fin, les pourcentages sont calculés pour comparer la présence des principales chaînes de supermarchés.

06Problèmes rencontrés / points complexes

Cette SAE a été assez difficile pour moi, principalement parce que je ne suis pas encore très à l'aise avec Python. J'ai dû prendre le temps de comprendre comment organiser les fonctions, comment récupérer une réponse d'API, comment accéder aux informations dans un dictionnaire JSON et comment éviter que le programme s'arrête dès qu'une donnée manque.

Une autre difficulté venait d'OpenStreetMap et de l'API Overpass. Le service était parfois surchargé par les requêtes, ce qui pouvait ralentir ou bloquer la récupération des données. Il fallait donc tester plusieurs fois, réduire ou adapter les requêtes et accepter que le résultat ne dépende pas uniquement du code, mais aussi de la disponibilité du serveur.

Le choix du sujet a aussi demandé du temps. Il fallait trouver un thème assez intéressant, mais surtout assez bien renseigné dans OpenStreetMap. Les supermarchés étaient un bon compromis, car ils sont nombreux, faciles à identifier avec un tag précis et permettent de produire des statistiques simples à comprendre.

Le traitement des données JSON a été le passage le plus technique. Les objets OpenStreetMap ne possèdent pas tous les mêmes champs : certains n'ont pas de nom, d'autres n'ont pas les tags attendus, et les enseignes peuvent être écrites différemment. Il fallait donc vérifier l'existence des données avant de les utiliser et prévoir des conditions pour éviter les erreurs.

La génération automatique du Markdown puis du HTML était aussi complexe, car le programme devait produire un résultat lisible sans écrire les statistiques à la main. Cela m'a obligé à mieux comprendre les fichiers, les chaînes de caractères, les boucles et la transformation d'un résultat brut en document exploitable.

def get_dataset(query: str) -> dict:
    url = "https://overpass-api.de/api/interpreter?data=" + str(query)
    r = requests.get(url)

    # Partie compliquée :
    # si le serveur Overpass est surchargé, cette ligne peut échouer

    rep = r.json()
    return rep

Traitement des données et calcul des statistiques

def compute_statist(data):
    carrefour = 0
    leclerc = 0
    intermarche = 0
    lidl = 0
    auchan = 0

    for element in data["elements"]:
        # Partie compliquée :
        # toutes les données OpenStreetMap n'ont pas les mêmes champs.
        # Il faut donc vérifier que "tags" et "name" existent
        # avant d'essayer de les utiliser.
        if "tags" not in element:
            continue
        if "name" not in element["tags"]:
            continue

        nom = element["tags"]["name"].lower()

        # Partie compliquée :
        # les noms ne sont pas toujours écrits exactement pareil.
        # Il faut donc chercher des mots dans le nom complet.
        if "carrefour" in nom:
            carrefour += 1
        elif "leclerc" in nom:
            leclerc += 1
        elif "intermarché" in nom or "intermarche" in nom:
            intermarche += 1
        elif "lidl" in nom:
            lidl += 1
        elif "auchan" in nom:
            auchan += 1

    total = carrefour + leclerc + intermarche + lidl + auchan

    # Partie compliquée :
    # il fallait transformer les comptages en pourcentages
    # pour obtenir une comparaison plus compréhensible.
    stat_carrefour = (carrefour * 100) / total
    stat_leclerc = (leclerc * 100) / total
    stat_intermarche = (intermarche * 100) / total
    stat_lidl = (lidl * 100) / total
    stat_auchan = (auchan * 100) / total

    return stat_carrefour, stat_leclerc, stat_intermarche, stat_lidl, stat_auchan

Génération du rapport Markdown puis HTML

def stats_supermarches(query, fichier_md: str, fichier_html: str):
    c, l, i, li, a = compute_statist(get_dataset(query))
    stats = {
        "Carrefour": c,
        "Leclerc": l,
        "Intermarché": i,
        "Lidl": li,
        "Auchan": a
    }

    contenu = "# Supermarchés en Normandie\n"
    contenu += "* lien osm :\n"

    # Partie compliquée :
    # il fallait générer un fichier lisible automatiquement,
    # sans écrire les résultats à la main.
    for nom, valeur in stats.items():
        contenu += "* " + str(nom) + ": " + str(valeur) + "\n"

    with open(fichier_md, "w") as f:
        f.write(contenu)

    with open(fichier_md, "r") as f:
        text = f.read()
        html = markdown.markdown(text)

    with open(fichier_html, "w") as f:
        f.write(html)

    return (
        "Résultats :",
        stats,
        "Le supermarché le plus présent en Normandie est :",
        max(stats, key=stats.get)
    )
